# Code of Conduct

## Our standard

OpenAgent-X is a safety-critical, open engineering project. We are professional, evidence-driven, and kind. Behavior that is welcome: rigorous critique with evidence, clear disagreement, patient onboarding, honest disclosure of limitations and failures.

Behavior that is unwelcome: harassment, discrimination, personal attacks, publishing others' private information, bad-faith security claims, hype over evidence.

## Responsibilities

Maintainers may remove, edit, or reject contributions that violate this Code and may ban contributors for repeated violations. Security reports follow the private process in `SECURITY.md`.

## Scope

Applies within project spaces (repo, issues, PRs, chats) and when representing the project publicly.
